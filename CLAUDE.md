# Atlantist BIM 2.0
## What this app does
Atlantist is a browser-based BIM platform. Engineers place walls, columns, levels, doors, and windows on a 3D model; changing any parameter instantly propagates through a DAG constraint solver to update all bound element geometry. Door and window placement on wall faces auto-cuts wall geometry to match family dimensions. Architects coordinate via integrated issue-tracking with live pins and real-time comment threads. A-400 schedules auto-populate from placed doors and windows.
## Stack
Node.js + Express + PostgreSQL (Neon) + Three.js (frontend) + ws (WebSocket) + EJS (unused post-Phase-1)
