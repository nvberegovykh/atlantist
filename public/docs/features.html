Analysis Engines

Live

Structural Analysis — OpenSees

OpenSees-powered finite element analysis. Animated deflection and stress viz in 3D. DCR (Demand-to-Capacity Ratio) color map from green to red. Code check results show PASS/FAIL per member. Beam types include AISC W-shapes, HSS, LVL. Stairs and railings built to IBC 1013/1014 compliance.

OpenSees
Live

Energy Simulation — EnergyPlus

ASHRAE JS simulation engine with gbXML export and IDF generation. 8,760-hour annual timeline with interactive player. EN-001 (energy use intensity) and EN-008 (outdoor air) NYC compliance checks. EN-1 Workbook tab exports .xlsm with actual building geometry baked in. Year Viz charts and heatmap for solar/cooling analysis.

EnergyPlus
Live

MEP Simulation — HVAC, Plumbing, Electrical

Three discipline-specific simulation runners. HVAC: VAV terminals, fan coils, diffusers, duct routing. Plumbing: water supply, waste, fixture counts. Electrical: panel boards, conduit sizing, load calculations. Disclaimer gate required before results. MEP fixture catalog pre-loaded by type.

MEP
Live

Fire Protection — NFPA & FDS Simulation

NFPA 13 (sprinkler), NFPA 101 (egress), NFPA 92 (smoke), and FDNY compliance calculations. FDS (Fire Dynamics Simulator) input generation with smoke, temperature, and pressure visualization modes. NIST fire formula simulation. Occupancy type drives occupant load and egress width calculations.

NFPA
Live

Geotechnical Engineering

Bearing capacity (Terzaghi, Meyerhof, Hansen), elastic and consolidation settlement, lateral earth pressure (Rankine, Coulomb), pile capacity (API, Meyerhof), slope stability. OpenSees .tcl input generation for custom runs. Soil profile builder with layered stratigraphy per borehole. Three.js visualization of soil strata and bearing zones.
