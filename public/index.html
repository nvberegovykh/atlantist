FAQ

Common questions

Is Atlantist free to use?

Yes. You can open the app and start modeling without signing in. Billing kicks in based on actual infrastructure usage — and the minimum charge is $5/mo. Most individual users pay under $10.

Do I need to install anything?

No. Atlantist runs entirely in your browser using WebGL via Three.js. No plugins, no desktop client, no Revit license required.

How does the pricing model work?

We charge 2× your actual infrastructure cost (compute + storage + bandwidth + simulations). The formula is bill = max($5, infra cost × 2). Your bill adjusts automatically — no estimation needed. See the full breakdown.

Can I import my Revit (.rvt) files?

Yes. Atlantist integrates with the Autodesk APS (formerly Forge) Model Derivative API to convert and import .rvt files. Walls, columns, doors, windows, and levels are mapped to native Atlantist elements.

What simulations are included?

Five engines are built in: Energy Analysis (NYECC EN-001–008 compliance), MEP (HVAC, plumbing, electrical), Fire Protection (NFPA 13/101/92 + FDNY), Geotechnical (bearing capacity, settlement, pile capacity), and Structural (placeholder — FEA integration coming Q3 2026).

Does it work on mobile?

The app loads and the BIM canvas is usable on tablets (768px+). Some toolbar features collapse into a mobile popover. For serious modeling work, a desktop or laptop with a pointer device is recommended.

How does collaboration work?

Invite teammates via magic-link email. Live presence shows ghost cursors and active-user indicators. Pinned 3D comments anchor to model geometry. All changes broadcast over WebSocket in real time.

Can I export to DXF or IFC?

Yes to both. DXF export targets R14/2000 CAD format. IFC export writes IFC 2x3 for round-tripping with Revit and ArchiCAD. gbXML export feeds energy analysis tools.

How is my data kept secure?

All data is encrypted in transit (TLS 1.3) and at rest (AES-256 on Neon PostgreSQL). The DAG constraint engine and every parametric change are logged in an immutable event ledger — nothing is silently overwritten. Sessions use short-lived hashed tokens. We don't sell or share your project data. For enterprise teams, a Data Processing Agreement (DPA) is available at atlantist.cloud/legal/dpa.

Can I use Atlantist to file with the NYC DOB?

Yes. The DOB Submission Package generates a 9-PDF zip (LS-1 cover, energy forms EN-001 through EN-008, and an IFC extract) formatted to NYC DOB requirements. The package is built directly from your live model — no manual PDF assembly. Available on the Annual plan and as an add-on.
