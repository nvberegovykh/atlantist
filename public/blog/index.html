03 — Simulation

Analysis engines for engineers

Every major simulation discipline is built in. OpenSees for structural, ASHRAE JS for energy, discipline-specific runners for MEP — all running on Atlantist's infrastructure with no external software required.

Live

Structural Analysis — OpenSees

Finite element analysis via OpenSees. Animated deflection and stress viz in 3D. DCR color map (green → red). Code check PASS/FAIL per member. AISC W-shapes, HSS, LVL beam types. IBC 1013/1014 stairs and railings.

Live

Energy Simulation — EnergyPlus

ASHRAE JS engine with gbXML export and IDF generation. 8,760-hour annual timeline with interactive player. EN-001/008 NYC compliance checks. EN-1 Workbook .xlsm export with building geometry baked in.

07 — Import / Export

BIM file interoperability

Import Revit .rvt files via Autodesk Forge Model Derivative API. Export IFC 2X3/4 for ArchiCAD/Revit round-trip. DXF R14/2000 for CAD. gbXML for energy simulation software. All routes have progress tracking and category-level statistics.

Live

.rvt Import — Autodesk Forge

Revit file import via Autodesk Forge Model Derivative API. Progress tracking: pending → uploading → converting → extracting → mapping → completed. Wall layer recreation, family instance placement. Element-by-element results with import status.

Live

IFC Export — 2X3 / IFC4

IFC STEP parser and exporter for ArchiCAD/Revit round-trip. IFC2X3 and IFC4 schema support. Element mapping with proper IfcProduct hierarchy. Level, wall, door, window, space geometry preserved.

Live

Import/Export Hub

Unified import/export management dashboard. IFC, DXF, gbXML, .rvt all in one place. Job status, file sizes, element counts, and download links.
