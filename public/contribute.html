The Platform

Browser-based BIM for architects & engineers

Atlantist replaces desktop BIM software with a precision parametric modeling platform that runs in any browser — no installs, no dongles, full collaboration.

✦

Parametric 3D modeling

Walls, columns, floors, doors, windows — connected by a DAG constraint solver that propagates changes across all views instantly.

✦

Energy & code compliance

NYECC EN-001 through EN-008, ASHRAE 90.1, NFPA life safety — live compliance checks, not a post-design afterthought.

✦

AI-assisted design

Wallt, the BIM AI companion, answers structural, MEP, and code questions in context — trained on the model your team is working on.

✦

Open source core

The BIM engine is Apache 2.0. Contributors own the roadmap, earn from the revenue, and review each other's code.

The Program

How it works

Four steps from GitHub to profit shares.

1

Connect GitHub

Sign in with GitHub OAuth. We verify your account and match your contributions automatically — no manual tracking.

2

Complete verification

Identity check and Contributor Agreement signature — required for payouts. Takes about 3 minutes.

3

Contribute & earn

Merge PRs, close issues, push commits. Points are credited automatically after each event. Check your balance any time.

4

Receive payouts

Set up Stripe for payouts. Points convert to profit shares at each distribution cycle based on your share of total points.
