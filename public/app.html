    Design Book

    Auto-generate floor plans, sections, and schedules from the current model. This creates sheet placeholders for every building level, plus door and window schedules from family instances.

    Sheets generated:

    What gets generated:
    • One floor plan sheet per building level (A-101-XXXXX)
    • Door schedule (A-400-DOORS) from all door instances
    • Window schedule (A-400-WINDOWS) from all window instances
    • Room schedule (A-400-ROOMS) from all room records
    • Finish schedule from wall assembly layers
    Sheets are editable — add annotations, dimensions, and product selections.

    The Violation Tracker will automatically flag code violations from placed BIM elements: IBC occupancy-load conflicts, ADA accessibility clearances, NYC DOB open violations linked to the project address, fire-egress path obstructions, and structural overstress warnings from the geotechnical engine.
    🏗️ IBC Code Checks
    Occupancy loads, exit widths, travel distances, egress door swing directions.
    ♿ ADA Compliance
